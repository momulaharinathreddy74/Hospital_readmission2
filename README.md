# Hospital Readmission & Cost Analytics Pipeline

Predicts which diabetic patients are likely to be readmitted within 30 days,
checks that the predicted probabilities are trustworthy, and estimates whether
a targeted follow-up program would save money.

Built on the [Diabetes 130-US Hospitals dataset](https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008)
(101,766 encounters, 130 hospitals, 1999-2008).

## Results

| | |
|---|---|
| Test ROC-AUC | **0.679** (published range for this dataset: ~0.64-0.70) |
| Calibration error (ECE) | 0.339 before, **0.008** after isotonic calibration |
| Top 20% of patients by risk | reach **39.7%** of readmissions (95% CI 37.8-41.4%), ~2x random |
| Gross avoidable cost (top tiers, 10-20% program effect) | **$6.7M-$13.3M** over the dataset |
| Net of a $500/patient program | **-$3.0M to +$3.7M**; break-even at $346-$691 per patient |

All numbers are on a held-out, patient-level test set and are regenerated by
the pipeline.

## What was found along the way

**A leaked feature.** A per-patient "total encounters" count correlated 0.235
with readmission, far above any legitimate feature (0.168). It counts future
visits, so it is unknowable at discharge. A point-in-time test showed its value
changed for 66% of rows when future data was hidden; left in, it would have
inflated AUC by about 0.11. Removed. (`reports/03_leakage_report.md`)

**A calibration bug.** Training with `class_weight="balanced"` gave slightly
better AUC but inflated average predicted risk to 45% against an 11% actual
rate. AUC can't detect this because it only measures ranking. Isotonic
regression fitted on validation brought every risk tier within about one point
of the actual rate. (`reports/05_calibration_report.md`)

**A tie bug from calibration.** Isotonic output is a step function, so about
1,000 test patients shared one calibrated value right at a tier cutoff, and a
1e-16 rounding difference moved all of them between tiers. Fixed by ranking on
the raw score (continuous, same order) and reporting calibrated probabilities.
A reproducibility check now guards it. (`reports/06_tiering_report.md`)

**Gross vs. net.** The program only pays for itself if it is effective enough
and cheap enough; enrolling fewer, higher-risk patients is more efficient.
(`reports/07_savings_report.md`)

**Departments.** After risk adjustment (observed/expected, with 95% CIs),
Nephrology's high raw rate (16.1%) reflects sicker patients (O/E 0.93).
Orthopedics is the only department significantly worse than expected
(O/E 1.40, CI 1.11-1.75).

## Run it

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python3 run_all.py                 # download data, run all steps, verify results
streamlit run app.py               # open the dashboard
```

`run_all.py` downloads the data from UCI (with a mirror as fallback), runs every
step in order, and checks the key results. `python3 run_all.py --from model`
restarts from a given step.

## Pipeline

| Step | Module | Output |
|---|---|---|
| 1. Ingest & audit | `src/ingest.py`, `src/audit.py` | validated raw data, data-quality report |
| 2. Clean & features | `src/clean.py`, `src/mappings.py` | UB-04 code groups, ICD-9 groups, exclusions |
| 3. Leakage checks | `src/leakage.py` | correlation, point-in-time, ablation and split tests |
| 4. Model | `src/model.py` | patient-level split, gradient boosting, tuning |
| 5. Calibration | `src/calibrate.py` | isotonic vs. Platt, per-tier check |
| 6. Tiering & lift | `src/tiering.py` | risk tiers, gains, bootstrap CI |
| 7. Costs & savings | `src/savings.py`, `src/assumptions.py` | department O/E, gross/net, sensitivity |
| 8. Dashboard | `app.py` | interactive simulator and charts |

Each step writes a report to `reports/`. All financial assumptions and their
sources live in `src/assumptions.py`.

## Limitations

- Data is 1999-2008 and diabetic encounters only; care patterns have changed.
- The totals cover 10 years and 130 hospitals, so they are not annual figures
  for one hospital.
- Costs are national averages (AHRQ HCUP), not hospital-specific.
- The simulation assumes the program works equally well at every risk level.
- 49% of encounters have no recorded department.

## Data source

Strack, B. et al. (2014). Impact of HbA1c Measurement on Hospital Readmission
Rates: Analysis of 70,000 Clinical Database Patient Records. *BioMed Research
International*, 781670.
